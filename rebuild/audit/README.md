# 1단계 조사 결과

조사 대상 런타임 코드: `c48651f3cb4f47dd43bf9eb0879c8bbb7693d012` (PR #69의 조사 시작점).

**1단계의 산출물은 현재 구조·요구 대비 차이·유지/수정/교체/이전 범위다. 게임 완성 판정이 아니다.** 이번 작업은 런타임 코드를 바꾸지 않았으며, 2~14단계는 시작/완료로 표시하지 않는다.

## 산출물과 조사 방식

- [80개 요구사항 대조표](REQUIREMENTS.md): 현재 코드, 부족한 점, 근거 위치, 다음 단계, 통과해야 할 시나리오.
- [구조·상태·재사용 범위](INVENTORY.md): 두 실행 계통, 주요 파일, 데이터·저장·권한·화면 연결, 중복·미사용 후보.
- [기존 검사의 보장 범위](TEST_SCOPE.md): 실제 검사하는 것과 검사하지 않는 것.
- [기계 추출 목록과 메모리 내 관찰](source-inventory.json): 104개 JS/HTML 파일의 해시·크기·명시적 함수/require/case, 고정 시드 관찰. `index.html`은 생성 파일로 별도 표시한다.
- [요구사항 원본 데이터](requirements.json): 사람이 판정한 항목과 근거. 파일 존재나 함수 개수로 완료율을 계산하지 않는다.

재현: 저장소 루트에서 `node scripts/audit-rebuild.js --write`. 일반 실행은 JSON을 표준 출력에만 보낸다. `--write`는 조사 폴더의 목록·대조표만 갱신한다. 실행 중인 서버·운영 저장·기존 게임 파일은 수정하지 않는다.

조사는 원본 `REBUILD_PLAN.md`의 모든 기능 영역, 새 14단계 계획, 구/신 런타임 진입점과 주요 처리 경로를 대상으로 한다. 모든 코드 줄의 결함을 발견했다거나 모든 실행 조합을 검증했다는 뜻은 아니다. 정규식 추출이 다루지 못하는 동적 HTML 삽입·VM·콜백·접두어 행동 분기는 수동으로 연결을 확인했다.

## 핵심 판정

1. **두 게임은 같은 시뮬레이션의 새 화면이 아니다.** `/classic`·`/god`는 `engine.js`, `/`·`/play`·`/editor`는 `rebuild/game.js`를 사용한다. 서로 다른 주민·경제·시간·저장 모델이다. 한 번에 Worker 하나만 실행하지만 모델의 분리는 그대로다.
2. **새 게임은 기존 학습 엔진을 재사용하지 않는다.** 기본 주민에게 `g/q`가 없고 하루 처리에서 읽지 않는다. 이전 시 원본에는 보관하지만 새 실행 상태에서는 제거한다. 서로 다른 `g/q`를 넣어 같은 하루를 진행한 관찰에서 새 뷰는 같았다.
3. **새 인물의 목표는 계획자가 아니다.** `schema.js`에서 두 가지 목표 문구를 정하고, 화면·면담에서 읽는다. 이직·가격·확장은 정해진 조건문이다. 목표 선택→계획→협상→실행→재계획을 수행하는 주체는 없다.
4. **지형·물류·주거는 축약 모델이다.** 기본 세계는 60명·3지역·9점포·3경로다. 경로의 거리·용량 계산은 있지만 실제 지형·도로·건물 위치에서 생성된 망은 아니다. 원료 종류 표시는 있어도 생산은 공통 `raw`를 소비한다. 주거는 지역 수용량과 플레이어의 소유 상태 값 중심이다.
5. **정치는 일부 기능을 가진 수치 모델이다.** 투표·표결·예산 집행은 있다. 경쟁 후보는 실제 인물이 아니라 산식의 상대 점수다. 의석도 고정된 지역별 배분 방식이다. 반대 세력 수치가 조직의 자율 행동으로 이어지지 않는다.
6. **협상·이야기는 한정된 분기다.** 납품·직원·후원·조달·상속 등의 실제 상태 변화는 있다. 하지만 돈·기간·권한·약속을 조합하는 일반 협상 체계가 아니라 사건마다 정한 선택이다.
7. **기존 저장 가져오기는 전체 이전이 아니다.** 40명 원본의 관찰에서 주택 18채는 새 주택 객체로 옮겨지지 않았고, 새 가족은 기본 가족으로 생성됐다. 별도의 미성년 표본은 6세→18세, 123일→0일로 바뀌었다. 회사는 명시적으로 비운다. 원본을 보관한다는 사실과 기존 권리·의무·분기를 이어간다는 요구를 구분해야 한다.
8. **기존 통과 검사는 전체 완료의 근거가 아니다.** 1,800일 검사는 정해진 행동과 주로 거절하는 선택을 반복한다. 5,000명 검사는 회사와 학습이 빠진 변환 상태의 10일 검사다. 모바일 검사는 일부 화면 크기와 작업만 확인한다. 각 검사의 구체적인 유효 범위는 별도 문서에 적었다.
