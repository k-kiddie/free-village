# 프리빌리지 리빌드 구현 기록

새 게임 주소: `/play`. 실행: 저장소 루트에서 `PORT=8080 node server.js`.
기존 `/`, `/god`와 별도인 `save/rebuild.json.gz`를 사용한다. 기존 저장을 새 규칙으로 자동 변환하지 않는다.

## 조사와 구조 결정

- `engine.js`의 `createWorld`, `dynStart`, `dynActions`, `dynStoryTick`은 주민 시뮬레이션과 가문 전용 명령·팝업·권한을 하나의 클로저에 결합한다. 새 계획의 시간 배분·사업 재고·약속을 부분적으로 끼우면 두 경제의 중복 처리가 생긴다. 새 전략 엔진은 `rebuild/game.js`로 분리했다. 기존 엔진의 유전자·학습은 새 엔진으로 이식하지 않았다.
- `sim-worker.js`는 엔진 전용 뷰와 기존 HTML 렌더러에 의존한다. 새 `rebuild/worker.js`가 서버의 동일한 Worker 프로토콜을 구현한다. `server.js`의 단일 활성 Worker와 세계 전환 직렬화를 재사용한다.
- `server-storage.js`의 스트리밍 gzip, fsync, 임시 파일 원자 교체를 재사용한다. 새 게임의 모든 성공 명령은 저장 완료 후 응답한다. 손상되거나 미래 버전인 저장은 덮어쓰지 않고 시작을 실패시킨다.
- `god-client.js`의 긴 행동 목록 대신 새 `index.html`과 `client.js`에서 지도·대상 패널·내 활동·사람을 제공한다. 서버에서 규칙을 실행하고 클라이언트는 결과만 받는다.

## 실제 구현한 플레이

- 3개 지역, 9개 입지, 60명의 주민. 매일 임금·소비·생산·원재료·임대·세금·배당을 실제 계정 간 이전한다.
- 3개 상품과 대량 판매·고품질·숙련 투자 방침. 지역/외부 공급의 단가와 운송 한계, 고용·임금·위임·확장·사업 정리. 경쟁자는 수요와 현금에 따라 방침을 바꾸고 입지를 차지하며 고용한다. 야심과 충성도가 이직에 영향을 준다.
- 시간 3칸을 개업·면담·조직·교육 등에 배분한다. 계획은 시간 경과로 완료되고, 일시정지·조건 중단 이유를 표시한다.
- 실제 공급과 고용이 지역별 지지에 반영된다. 면담·조직·공약·출마, 30일 주기 선거, 당선 후 국고로 도로·학교 집행과 세율 조정, 실각·낙선 후 재출마를 제공한다. 교육은 지역 주민 숙련에도 영향을 준다.
- 사업 상태에서 납품 협상이 발생한다. 수락·작은 계약 역제안·거절, 재고와 실제 구매자 자금에 따른 납품, 기한 초과 후 관계·신뢰 변화가 저장된다. 표시·실행·날짜 진행 때 자격을 다시 검사한다.
- 품팔이로 재기 가능. 후계자 교육과 120일 이후 세대 계승. 사업·자산은 유지되고 개인 신뢰와 인맥은 일부 감소한다.
- 중요한 협상만 시간을 정지한다. 일상 완료는 소식으로 요약한다. 새 화면은 외부 이미지 요청이 없어 삽화 다운로드가 선택을 가리지 않는다.

## 계획과의 차이 / 아직 필요한 작업

이는 계획의 핵심 흐름을 연결한 **첫 플레이 빌드**다. REBUILD_PLAN.md 전체 완료가 아니다.

- 기존 가문 모드의 보고된 사건·혁명·회계 문제를 모두 수정한 것은 아니다. 새 게임은 해당 경로를 사용하지 않는다. 기존 모드는 별도 유지한다.
- 실제 공간 좌표·물류 경로·주거 시장, 세력별 의회와 체제 전환, 깊은 인물 협상·혼인·상속 분쟁은 아직 없다. 현재 지역 지도는 입지 선택용 도식이다.
- 선거는 집단별 투표 대신 지역 생활 지표와 신뢰·조직·공약을 쓰는 초기 모델이다. 지역별 원인은 표시하지만 집단별 상세 설명이 필요하다.
- 새 게임의 세계 편집용 갓모드는 아직 없다. 기존 `/god`는 구 가문 게임이지 새 세계의 편집기가 아니다.
- 기존 저장의 새 게임 이행은 미지원이다. 원본을 손실 없이 유지하며 새 게임을 별도 시작한다.
- 인물 UI는 우선 20명을 표시한다. 세력별 탐색, 거래 대상 선택, 경제 균형과 장기 플레이 튜닝이 필요하다.
- AWS 배포·실제 휴대폰 성능·5,000명 확장은 검증하지 않았다. 현재 60명 소지역 게임이다.

## 검증

- `node scripts/check-rebuild.js`: 통화량 보존, 실패 명령의 원자성, 권한, 중복 고용, 방침별 결과, 협상과 시간 정지, 약속 후속 결과, 선거, 공공 예산, 계승, 저장 round-trip과 복원 후 동일 진행.
- `node scripts/check-rebuild-ui.js`: 실제 HTTP/Chromium, 360·390·820px, 가로 넘침, 개업→고용→시간 진행, 저장 파일, ETag 304, 기존 `/`·`/god` 페이지 제공.
