# 5단계 — 생활·교육·지역 경제

`/rebuild`의 기준 세계에 생활 행동과 지역 차이를 연결했다. 주민·현금·물품·주거·임금·학력·기술의 원본은 계속 `engine.js`다. 별도 인구나 지갑, 두 번째 하루 계산은 없다. 생활 화면·지도 레이어·생활권 비교는 같은 실제 세계를 읽는다.

## 실제 개입과 비용

| 기능 | 실제 변화와 제약 |
| --- | --- |
| 식량 구매 | 같은 생활권의 실제 주민이 기본 비축을 넘겨 보유한 곡식만 구매. 개인 현금→판매자 현금, 실제 재고·품질 이전, 기존 소득/지출·세금 기록 |
| 임대·이사 | 가까운 실제 공실, 살아 있는 임대인 또는 공공 임대 주체, 주택 상태·보증금 권리 확인. 첫 임대료는 다음 열흘 정산까지 기간분 납부, 이후 기존 엔진 수금·체납 규칙 사용. 같은 집의 배우자·부양 자녀도 이동 |
| 여유 시간 | 하루의 기존 생산/일과 밖에서 4시간. 구매·가족 지원 0.5시간, 기술 수업 1~2시간, 휴식 1~4시간, 이사 2시간+거리/160. 활동은 피로·배고픔에도 반영. 사용 시간은 저장되며 실제 날짜가 바뀌어야 초기화 |
| 기술 수업 | 같은 생활권의 성년 숙련자에게 실제 수업료 지급. 교사 본인의 여유 시간과 하루 수업 2시간 한도도 사용. 기술 차이·학생 영양·건강에 비례해 기존 `skill` 성장. 구금·복무·여행·교사 건강/일정 등 조건 재확인 |
| 학력 교육 | 기존 성인 기초/중등·진학·자녀 교육 경로와 학습 기간 유지. 기존 교사 수업·가정교육·자녀 과외에 실제 통학 거리와 영양/건강 조건 연결. 기초 교육은 실제 활동 교사 접근이 있어야 진척. 수업료만 내고 학력이 생기지 않음 |
| 가족 부양 | 실제 배우자·부모·자녀에게 내 곡식 이전. 가족의 재고가 바뀌고 이후 기존 소비 계산을 거침. 돈이나 식량을 새로 만들거나 정치 지지를 즉시 올리지 않음 |
| 가계·일 지침 | 생활 수준·자녀 과외·저축을 기존 5일 가계 정산에 연결. 일 우선순위·실제 일감·고용/임금·금고는 기존 공통 명령 사용. 생산과 임금은 기존 하루 계산이 수행 |

모든 새 행동은 공통 미리보기→현재 revision/잔액/재고/시간/대상 조건 재검사→원자적 집행→디스크 저장→응답을 거친다. 개인 자금이 없으면 가문 금고나 공공 예산을 대신 쓰지 않는다. 미리보기에는 상대 주민의 g/q를 복제하지 않는다. 기술 수업은 학력 교육과 구분한다.

4시간·통학 96거리·단일 이사 160거리·수업 성장률·가격 반응 범위는 현재 명시적인 균형 매개변수다. 현실 시간이나 모든 시드의 최적 균형을 검증한 수치로 주장하지 않는다. 물리적 도로 경로·배송·사업 공급망은 6단계다.

## 생활권과 경제 차이

실제 행정구역이 있으면 그 구역을 쓰고, 없으면 실제 주거 좌표를 64×64 생활권으로 묶는다. 집 없는 주민은 실제 공터 생활권에 속한다. 생활권을 새 정부나 세력으로 만들지 않는다.

- 실제 인구·아동·현금·당일 기록 소득·식량 재고·굶주림·주거 없음·고용 연결·휴식 성인·학습자·최근 교사·임대료·공실을 집계한다. 휴식한 성인을 실업자로 단정하지 않는다.
- 식량의 인당 재고와 굶주림 비율이 **기존 곡식/식사 경매의 실제 호가**에 영향을 준다. 판매 호가 배율은 0.85~1.25, 구매 호가는 0.9~1.15 범위다. 이후 기존 주문 정렬·현금 한도·매칭·소비·재고 규칙을 그대로 거친다. 별도 가짜 시장이나 보조금은 없다.
- 생활권 거래가는 실제 체결량/금액의 가중 평균이다. 서로 다른 품질의 거래도 포함한다. 체결이 없으면 미확인으로 표시하며 세계 평균가를 지역 관측가로 꾸미지 않는다.
- 생활 압박은 식량 부족·주거 없음·임대료 지불 능력·건강으로 산출한 필요 지표다. 피로 원인도 따로 표시한다. 이것을 정치 지지율로 간주하지 않는다. 집단 가치·신뢰·정치 반응은 7·9단계다.
- 날짜별 최대 30일의 실제 지역 관측과 출생·사망·외부 유입/이탈·주소 이동을 저장한다. 집은 같은데 구역만 바뀌면 행정구역 재편으로 구분한다. 최근 내 생활 개입도 지역별로 함께 열람한다. 변화 전체를 한 행동의 효과로 단정하지 않는다.

## UI와 경량 조회

생활 화면에서 실제 식량 구매 수량·수업 상대/비용·시간·임대 매물/다음 정산일·가족 식량·가계 지침·학습 진척을 보고 같은 미리보기로 실행한다. 지도에 식량·생활 압박 레이어를 추가했으며 집 없는 주민의 실제 공터도 별도로 표시한다. 생활권 비교에서 식량/주거, 일/교육, 인구 이동을 전환하고 지역별 관측 기록을 연다. 계약과 숙련·재고·자금·시간 변화는 활동 화면에서도 확인한다.

`GET /rebuild/api/living`은 요청 시 Worker에서 구성·gzip 응답한다. 일반 `/view` 응답에 전체 지역 이력이나 주민을 넣지 않는다. 지도는 구역 참조만 추가한다. 브라우저는 경제 계산을 수행하지 않는다. 금액은 기존 화폐 표시 단위를 따른다.

## 저장과 계산 연속성

canonical envelope는 v3이며 v1·v2 저장을 읽는다. `strategy.living`에 관측·이동 비교용 신원/주소·시간 사용·수업 한도·당일 거래 집계·개입 기록을 보존한다. 이전 저장에 없던 지역 과거 이력을 만들어 내지 않는다. observer 저장을 자동으로 strategy로 바꾸지 않는다.

기존 native v1 저장이 제외하던 항목 중 이후 계산에 영향을 주는 월별 예약 난수, 전날 일자리, 금융/정책 기준, 주민 순회 순서, 주주 캐시 순서를 canonical `continuation`에 보존한다. 실행 중 보유한 사망 주민의 전체 기록도 보존해 참조와 계산을 이어간다. 기존 저장에서 이미 사라진 과거 사망자의 g/q를 복원할 수 있다고 주장하지 않는다. 새 canonical 세계의 도로 기본값은 native import와 같이 0으로 맞춘다.

기존 `exportState()` 형식과 classic 실행은 바꾸지 않았다. 생활 hook은 strategy session에만 연결한다. 예전 마을의 난수와 g/q를 그대로 두며 인구나 학습 상태를 줄여 성능 문제를 피하지 않는다.

## 검증과 경계

- `check-living-economy.js`: 통제한 120명 세계에서 실제 현금/재고 보존·미리보기 불변·시간 한도·JSON 복원/재전송·영양별 기술 성장·재고별 지역 가격·교사 거리별 교육 진척·가족 이동·다음 임대료 수금·금고 대납 거절·오래된 견적 거절·v2 비파괴 이전·저장 다음 하루 동일을 검사한다. 같은 건축 수업의 숙련 증가는 건강/영양 조건에서 0.014546875, 영양 부족 조건에서 0.005104167이었다. 같은 상품 견적은 재고 풍부 지역 1.7, 부족 지역 약 2.4622였다.
- `check-living-ui.js`: 통제한 120명 세계의 **실제 모바일 UI 조작**으로 식량 수량·기술 수업·휴식/시간 거절·가계 지침·생활권 비교/기록·임대·지도·프로세스 재시작 후 시간 유지/다음 날 초기화를 검사한다. 임대 매물과 수업 조건은 검사 fixture이며 일반 시작 조건으로 주장하지 않는다.
- `check-living-continuation.js`: 별도 시드 7·19, 각각 일반 5,000명 시작과 자연 출생/사망을 거쳐 35일 저장·36일 계산, 30일 관측 유지, JSON 복원 후 다음 하루의 전체 canonical 상태/난수 동일을 검사한다. 36일 생존 인구는 각각 5,348명·5,330명이었으며 인구를 줄이지 않았다.
- `check-normal-play-ui.js`: 일반 시드 42·기본 5,000명·빈 저장에서 실제 대출→건설→UI 날짜/결정 처리→공사 중 서버 재시작→회사 설립을 다시 검사한다. 이 경로에는 자금·기술·공사 진척 주입이 없다. 5단계 반영 후 재검사에서도 초기 현금 69냥으로 시작해 실제 UI 41일·도중 결정 4건을 처리하고 첫걸음상사를 설립했다. 종료 현금은 10.826972642908645냥, 생존 인구는 5,366명이었다.
- 기존 `check-canonical-session.js`, `check-common-commands.js`, `check-command-internals.js`(비정렬 주주 캐시의 저장 다음 계산 포함), `check-transient-dead-save.js`, `check-canonical-view.js`, `check-canonical-http.js`, `check-canonical-ui.js` 회귀 및 `check-village-invariance.js`를 검사한다. 원래 마을의 Node24/300명/900일 기준은 `0404e02cd23c2e5b6e849814c8ec5074ed5b35b3`다.
